# Reforco-Escolar

## Como executar

### Pré-requisitos

- Node.js e npm instalados
- Git instalado (caso o projeto seja clonado)

### Instalação

Clone o repositório e entre na pasta do projeto:

```bash
git clone https://github.com/Artur242/Reforco-Escolar.git
cd Reforco-Escolar
```

Instale as dependências:

```bash
npm install
```

### Compilação

Para compilar o código TypeScript:

```bash
npm run build
```
